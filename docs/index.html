Spatial caution

MRNF covers productive stands inside the AOI, not the full mapped forest area. The carbon comparison keeps this denominator explicit.

Disturbance

Only part of the landscape has directly dated canopy loss.

Hansen loss year identifies pixels with dated canopy loss since 2001. The undated majority cannot be assigned a stand age from Hansen alone; it is simply outside that dated-loss window.

Attribution

The dated loss is a non-fire residual.

NBAC fire perimeters do not intersect this AOI for 1972-2023. In this managed forest context, the residual is interpreted as probable harvest, not a direct harvest observation.

Carbon

AGB is product-dependent here.

ESA CCI, SCANFI, and MRNF do not collapse to one number. The site shows them side by side and keeps SoilGrids SOC 0-30 cm as a separate pool.

Uncertainty

Common footprint, same stands, different answers.

The MRNF productive-stand footprint covers 2,489.6 ha and 431 peuplements. On that exact footprint, ESA remains high and SCANFI remains low relative to MRNF.

Bars by MRNF biomass class: MRNF in green, ESA CCI in red, SCANFI in blue. ESA shows a positive bias across classes; SCANFI shows a negative bias except in the lowest biomass class.

Stand-level check

SCANFI has lower area-weighted RMSE than ESA relative to MRNF: 41.2 vs 72.4 Mg biomass/ha.

Careful interpretation

MRNF is the most locally relevant provincial inventory-derived reference for productive stands, but it is not ground truth. This is a structured cross-product uncertainty result.

Data and methods

Static story, reproducible pipeline.

The page is a GitHub Pages front end for the validated scripts and outputs. No API keys, build step, or live Earth Engine call is required to view it.

Disturbance

Hansen Global Forest Change v1.13 provides tree cover and dated canopy loss. NBAC provides the independent fire-perimeter check.

Recovery

Sentinel-2 SR Harmonized provides the 2024 NBR composite used for the probable post-harvest spectral recovery chronosequence.

Carbon

ESA CCI, SCANFI, MRNF Quebec, and SoilGrids are presented as distinct products and pools. AGB + SOC is not presented as total ecosystem carbon.

The interactive map shows only the AOI because this repository does not include static geospatial exports for Hansen loss pixels, NBAC perimeters, MRNF stand geometry, or ESA/SCANFI raster subsets.
