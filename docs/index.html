Forest Question

How can open satellite records reconstruct recent forest disturbance?

The workflow combines Hansen canopy-loss dates, Canadian fire records, and Sentinel-2 observations to examine post-disturbance spectral vegetation recovery in a managed boreal landscape in Abitibi, Quebec.

Hansen loss is dated canopy loss, not stand age. Non-fire residual loss is probable harvest in this managed forest context, not direct harvest observation. NBR is spectral vegetation recovery.

Interpretation

What the workflow supports, and what it does not.

The analysis supports a conservative disturbance narrative: detected Hansen canopy loss is dated, no NBAC fire overlap is mapped in the AOI, and the residual is treated as probable harvest in this managed forest context.

The recovery curve is spectral. It should not be read as stand age, stand maturity, productivity, or direct field validation. The >=100 pixel filter is a pragmatic support threshold, not a formal significance test.
