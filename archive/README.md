Legacy outputs and exploratory notebooks
========================================

This archive separates outputs from earlier exploratory phases of the
project from the current Abitibi-focused analysis pipeline.

Current pipeline
----------------

The current reproducible pipeline is defined by:

- analysis/01_stand_age.py
- analysis/02_disturbance_attribution.py
- analysis/03_recovery_curve.py
- analysis/04_carbon.py
- analysis/05_agb_sensitivity.py
- analysis/06_agb_crosscheck_scanfi.py

Those scripts use the verified Abitibi analysis zone from src/zones.py and
the current modules in src/.

Legacy outputs
--------------

The files in archive/legacy_outputs/ came from earlier cross-biome,
regional-balance, or notebook-driven work. They should not be interpreted
as outputs of the current Abitibi 10,000 ha pipeline unless regenerated by
one of the current scripts.

This distinction matters because some legacy carbon tables report values
from older AOIs or methods. For example, carbon_comparison.csv reports
47.59 Mg C/ha for "Boreal managed forest (Abitibi, Quebec)", while the
current Abitibi pipeline reports ~80.8 Mg C/ha from analysis/04_carbon.py.

Notebooks
---------

The notebooks remain in notebooks/ for now, but they are exploratory
records rather than the authoritative execution path. In particular,
notebooks/01_extraccion_y_balance.ipynb references modules that are not
present in the current src/ tree and should not be used to reproduce the
current README results.
